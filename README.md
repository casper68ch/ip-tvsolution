# IP-Tv.Solution

**Solo player. Nessun contenuto.**

IP-Tv.Solution è un portale che raccoglie guide all'installazione di **player IPTV legittimi** per Android, Android TV, Windows, Web/Chrome, LG webOS, Samsung Tizen, Apple e Linux, oltre alle cinque edizioni del progetto (v1.9).

🌐 **Sito ufficiale:** https://ip-tvsolution.online
📧 **Contatti:** ip.tv-solution@tutamail.com

> ⚠️ **Avvertenza legale.** IP-Tv.Solution distribuisce esclusivamente player multimediali. Nessun canale, playlist, abbonamento o credenziale IPTV è fornito. Gli utenti configurano i player con fonti di cui possiedono i diritti. I marchi citati appartengono ai rispettivi proprietari e sono usati a scopo informativo.

## Installazione rapida

1. Scegli la tua piattaforma nella tabella sopra.
2. Scarica il pacchetto dal link ufficiale corrispondente.
3. Segui la guida passo-passo sul sito (abilita l'installazione da origini sconosciute solo su Android/Fire TV e la Developer Mode su LG/Samsung).
4. Al primo avvio crea il tuo account (nome utente, password, email): la richiesta di attivazione viene inviata al proprietario.
5. Dopo l'approvazione ricevi via email il codice `IPTV-XXXXXXXX` da inserire nell'app.

Nessuna playlist o credenziale è inclusa nei pacchetti.

## Sviluppo

```bash
npm install
npm run dev       # sviluppo locale
npm run build     # build statico in out/
npm run deploy    # build + deploy su Cloudflare Pages
```

Next.js 15 (App Router, TypeScript, Tailwind v4), output statico `out/`, 21 player catalogati, 8 piattaforme, SEO con JSON-LD e sitemap generata.
